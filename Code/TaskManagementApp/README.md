# TaskManagementApp

Day la source code Android cua de tai TaskManagementApp.

## Cong nghe nen

- Kotlin
- XML + ViewBinding
- MVVM + Repository
- Room
- DataStore
- Lifecycle ViewModel, LiveData/Flow
- AlarmManager + BroadcastReceiver
- NotificationManager + quyen Android 13+
- JSON + Storage Access Framework

## Chay project

```text
.\gradlew.bat assembleDebug
```

Mo thu muc nay bang Android Studio de sync Gradle va chay tren emulator/thiet bi Android.
