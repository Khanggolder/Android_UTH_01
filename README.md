## Gioi thieu

TaskManagementApp la ung dung Android ho tro quan ly cong viec ca nhan. Ung dung huong toi viec tao, theo doi va sap xep cac task trong qua trinh hoc tap va lam viec.

## Kien truc he thong

- Mo hinh: Android mobile application
- Protocol: Chua ap dung
- Port mac dinh: Khong co
- Cau truc message: Chua ap dung

## Yeu cau moi truong

- He dieu hanh: Windows
- Ngon ngu: Kotlin
- Cong cu hoac dependency: Android Studio, Gradle Wrapper, Android SDK theo cau hinh du an

## Cai dat

Mo project Android tai thu muc `Code/TaskManagementApp/` bang Android Studio va de Gradle dong bo dependency.

## Huong dan chay

### Server

```text
Khong co server rieng trong phien ban hien tai.
```

### Client

```text
Mo Code/TaskManagementApp bang Android Studio, chon thiet bi/emulator va chay app module.
```

Hoac dung terminal:

```text
cd Code/TaskManagementApp
.\gradlew.bat assembleDebug
```
